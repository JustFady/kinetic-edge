# ⚡ Kinetic-Edge — AI Basketball Referee Assistant

**Kinetic-Edge** is an ultra-low-latency AI video processing pipeline designed to track players, basketballs, and assist human referee decision-making (out-of-bounds, sudden acceleration/fouls, and possession changes) in real time.

## 🚀 Hugging Face Space Quickstart

This Space runs the containerized Kinetic-Edge web interface with live video analysis and real-time bounding box overlays.

### Local Installation via PyPI
```bash
pip install kinetic-edge
kinetic-edge app
```
